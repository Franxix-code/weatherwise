🌦️ WeatherWise

WeatherWise is a full-stack weather web application built with Django, HTML, CSS, and JavaScript.

The application allows users to search for weather information by city and also uses browser geolocation to provide weather information based on the user's location.

It integrates weather data from the OpenWeather API and provides current weather conditions alongside a 5-day forecast.

🎯 Project Goal

The goal of WeatherWise was to build a practical weather application that combines a Python/Django backend with an interactive frontend while exploring APIs, browser geolocation, voice interaction, and responsive web design.
