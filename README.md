🌦️ WeatherWise

WeatherWise is a full-stack weather web application built with Django, HTML, CSS, and JavaScript.

The application allows users to search for weather information by city and also uses browser geolocation to provide weather information based on the user's location.

It integrates weather data from the OpenWeather API and provides current weather conditions alongside a 5-day forecast.

🎯 Project Goal

The goal of WeatherWise was to build a practical weather application that combines a Python/Django backend with an interactive frontend while exploring APIs, browser geolocation, voice interaction, and responsive web design.
✨ Features

- 🔍 City Weather Search — Search for weather information by city.
- 📍 Automatic Location Detection — Uses browser geolocation to retrieve weather information based on the user's location.
- 🌡️ Current Weather Information — Displays important weather conditions for the selected location.
- 📅 5-Day Forecast — Provides a forecast for the upcoming five days.
- 🎤 Voice Input — Allows users to interact with the application using browser speech recognition.
- 🔊 Text-to-Speech — Reads weather information aloud using browser speech synthesis.
- 📱 Responsive Design — Designed to work across different screen sizes.
- 🌐 OpenWeather API Integration — Retrieves real-time weather data from an external weather API.
